### Problem Statement:

Given an integer array `nums`, find the subarray with the largest sum, and return the sum.

### Examples

| Input                          | Output | Explanation                                       |
|--------------------------------|--------|---------------------------------------------------|
| nums = [-2,1,-3,4,-1,2,1,-5,4] | 6      | The subarray [4,-1,2,1] has the largest sum 6.    |
| nums = [1]                     | 1      | The subarray [1] has the largest sum 1.           |
| nums = [5,4,-1,7,8]            | 23     | The subarray [5,4,-1,7,8] has the largest sum 23. |

### Constraints

- <code>1 <= nums.length <= 10<sup>5</sup></code>
- <code>-10<sup>-4</sup> <= nums[i] <= 10<sup>4</sup></code>

### Follow Up:
